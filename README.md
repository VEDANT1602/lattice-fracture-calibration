# How far can a uniform-lattice calibration travel across a stiffness patch?

Cutting a loaded spring releases two stores of elastic energy. The spring loses its own stored energy, and its neighbours relax. A calibration on a uniform lattice captures much of the second effect. This benchmark measures the error that remains when a soft or stiff patch is placed near a notch.

## The mechanical experiment

A square lattice carries antiplane shear between fixed grips. The simulation raises the grip separation until the prescribed tip spring reaches unit force. It computes equilibrium before and after cutting that spring at the same grip displacement. The difference in total elastic energy is the reference release. A second calculation uses the intact lattice compliance and a rank-one stiffness update to check the result.

The grid crosses four specimen widths, two notch lengths, three patch locations, two patch radii and seven stiffness ratios. The 336 design rows comprise 288 nonuniform configurations and 48 homogeneous controls. Every geometry is generated by the script.

## What the correction captures

| Release predictor | Mean absolute relative error on 288 nonuniform configurations |
|---|---:|
| Energy in the tip spring | 57.66% |
| Tip energy × geometry-matched homogeneous multiplier | 4.18% |
| Multiplier adjusted by its local slope against patch stiffness | 0.43% |

Patch location matters. For the smaller radius, the homogeneous multiplier has 13.88% mean error when the patch is centred on the tip. Moving it four spacings behind the tip reduces the error to 0.15%. The slope correction uses two calibration solves within about 1% of the uniform state. Its largest error across the nonuniform grid is 5.96%.

The benchmark prescribes which spring breaks first. It measures the energy for one cut at fixed grip separation. A physical toughness measurement would require following crack advance, identifying the failure path and measuring the work per newly created area.

## Reproduce the calculations

Run from the repository root with Python 3.11. The study used Python 3.11.9, NumPy 1.26.0 and SciPy 1.11.2.

```bash
python -m pip install -r requirements.txt
python run.py
python verify.py
```

`run.py` rebuilds the lattices, solves the equilibrium systems and writes `results.csv`. `verify.py` uses the Python standard library to check the configuration counts, recompute the error table and verify agreement between the two energy calculations.
